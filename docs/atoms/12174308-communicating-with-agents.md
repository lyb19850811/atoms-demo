# 与智能体沟通

> 来源：https://help.atoms.dev/zh/articles/12174308-communicating-with-agents
> 更新时间：2026年7月29日

以下是一份结构化指南，帮助你高效地与团队协作：

## 智能体角色

Atoms 团队由七位专业智能体组成，每位都具备特定专长：

- Mike（团队负责人）：分配任务并协调团队。
- Emma（产品经理）：负责产品需求分析和市场调研。
- Bob（架构师）：设计系统架构和技术解决方案。
- Alex（工程师）：专注于应用开发、快速修复 bug 和功能实现。
- David（数据分析师）：负责数据处理、机器学习、网页抓取以及数据驱动的问答任务。
- Iris（深度研究员）：为工作、学习或决策收集、分析并总结信息。
- Sarah（SEO 专家）：生成多语言 SEO 内容以提升流量。

## 沟通技巧

- 对于复杂任务：从最小可行产品（MVP）开始，然后逐步改进每个模块。
- 清晰是关键：

  - 概述目标、重要细节和示例，以提供上下文。
  - 使用结构化格式（例如 Markdown）来组织需求。
- 反馈很重要：提供积极反馈，以保持稳定的表现和质量。
