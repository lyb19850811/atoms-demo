# 分享

> 来源：https://help.atoms.dev/zh/articles/12129279-share
> 更新时间：2026年7月29日

**分享** 菜单是你的分发控制中心。它允许你下载项目文件、管理访问权限、复制分享链接，或直接发布到社交平台。你可以在界面右上角找到“分享”按钮。

## 如何使用

### 导出
点击 **导出** 以获取完整的 Chat .zip 文件。浏览器会自动下载一个包含所有代码和资源的压缩包。

### 访问权限
控制谁可以查看你的项目：
- **公开**：任何拥有链接的人都可以查看你的 Chat 和界面。公开项目有机会在 App 世界中获得功能展示。
- **秘密**：只有拥有直接链接的人才能访问你的项目。
- **私密**：只有你自己可以访问和查看你的项目。

### 分享到社交平台
可直接将你的作品分享到 X (Twitter)、Instagram、LinkedIn 或 TikTok，并附带预格式化的帖子和预览卡片。

### App 卡片和 App 世界
当 Chat 权限设置为公开时，默认可以发布到 App 世界。在你的 App 卡片上，你可以自定义封面、编辑项目标题、指定发布版本，并为社区成员提供项目描述。

## 使用场景

1. **Elias** 想要快速下载他在 Atoms 上的项目，于是他在 **分享** 中点击 **导出** 来获取 zip 文件。
2. **Vivian** 对她的新应用感到很兴奋，想要展示出来，于是她点击 **X (Twitter)** 图标立即发布。
3. **Carol** 想让自己在 App 世界中的项目介绍更有趣，因此她编辑了自己的 App 卡片。

## FAQ

<AccordionGroup>
<Accordion title="我可以在哪里下载项目文件？">

打开 **分享** 菜单并点击 **导出**。这会将与你当前项目相关的所有代码文件和资源打包为可下载的 .zip 压缩包。

</Accordion>
<Accordion title="我可以把公开的 Chat 改成私密吗？">

可以。点击 **分享** 面板中的权限下拉菜单，即可随时在 **公开**、**秘密**（仅链接可访问）和 **私密** 之间切换。

</Accordion>
<Accordion title="我可以将应用分享到 App 世界吗？">

当然可以。默认情况下，公开项目会分享到 App 世界，让社区能够查看、测试和克隆你的作品。

</Accordion>
<Accordion title="我可以将应用分享到其他社交媒体平台吗？">

可以。你可以使用 **分享** 下拉菜单中的社交图标，直接分享到 X (Twitter)、Instagram、LinkedIn 和 TikTok。

</Accordion>
<Accordion title="私密项目和公开项目有什么区别？">

当你将项目设为公开时，你可以：
- 与他人分享对话链接。
- 允许他人查看你与智能体的互动以及项目输出。
- 展示有趣的使用场景和对话技巧。

*注意：其他人只能查看你的项目内容和输出，无法修改你的原始项目。*

</Accordion>
<Accordion title="什么是 App 世界？分享能带来什么好处？">

**App 世界** 是 Atoms 用于展示创作者项目的平台，你可以：
- 在首页展示你的作品和提示词工程技能。
- 启发他人学习并基于你的贡献继续构建。
- 使用右上角的 **分享** 按钮轻松分享你的项目。

作为贡献者，你可以：
- 帮助壮大 Atoms 创作者社区。
- 获得其他用户的认可和反馈。
- 有机会获得官方奖励和精选展示。

</Accordion>
<Accordion title="在分享到 App 世界之前，我需要了解什么？">

一旦分享，所有聊天记录和代码都将对社区成员公开可见。
- 请确保你的内容 **不** 包含敏感个人信息、密码、API 密钥或机密数据，以避免潜在的安全风险。
- 请确保你的内容符合所有适用的法律法规和服务条款。

</Accordion>
<Accordion title="如果我在分享后继续开发，共享版本会发生什么？">

当你将某个版本（例如 v2.0）分享到 App 世界时，它会记录应用界面和完整的对话历史。

如果你继续在原始聊天线程中开发新版本（例如 v3.0）：
- App 世界仍会显示已发布的 v2.0 界面。
- 用户可以在对话线程中查看 v3.0 更新。
- 你可以选择发布 v3.0，以替换现有的 v2.0 展示版本。

*若要进行独立的私密开发，我们建议使用 **克隆** 创建一个新的对话线程，这样你的共享版本就不会受到影响。*

</Accordion>
