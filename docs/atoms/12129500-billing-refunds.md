## Cloud & AI 计费指南

Cloud & AI 的使用费用根据您已发布应用实际消耗的资源收取。

* **Cloud Infrastructure**：计算、数据库存储、Serverless 执行和对象存储。
* **AI Model Inference**：已发布应用中 GPT、Claude 和 LLM 调用的 API 使用。
* **Quota Priority**：优先使用免费的 Cloud/AI 配额。超出部分将从您的 Cloud & AI Wallet 中扣除。
* **Resource Pricing**：数据库存储 (\$0.525/GB-month)、Serverless 请求 (\$0.30/1M requests)、对象存储空间 (\$0.025/GB-month)。
* **Monitoring**：可在 **Settings** → **Cloud & AI** → **Usage** 下每日查看使用情况。设置余额提醒或月度限额以控制支出。

## 我如何申请退款？

原则上，一旦服务开始（即积分开始被消耗），付款将不予退款。但是，在符合特定条件的情况下，可能会提供退款或积分补偿。

**申请退款方式**：

1. 点击您的头像 → **Help Center** → 点击右下角的聊天图标联系支持团队。
2. 提供您注册账户的邮箱、发票截图以及付款凭证。
3. 说明您申请的是现金退款还是积分补偿。我们的支持团队将在 24 小时内审核并回复。
