# 发布

> 来源：https://help.atoms.dev/zh/articles/12129484-publish
> 更新时间：2026年7月29日

**发布** 功能会为您的 Web 应用程序生成一个稳定的公开链接，使任何人都可以访问并与您的线上项目进行交互。

## 如何发布您的项目

1. **点击发布**：在编辑器界面的右上角找到并点击 **发布** 按钮。
2. **配置自定义域名**：发布后，您可以为您的应用程序配置 **自定义域名**。
3. **取消发布选项**：如果您需要让站点下线，请点击位于发布菜单左下角的 **取消发布**。

### 发布与版本控制

- **更新按钮**：当您的项目上线后，**发布** 按钮会变为 **更新**。每当您想将新的更改推送到公开版本时，请点击 **更新**。
- **版本选择器**：
  - **始终为最新**：自动将线上站点更新为您最近的构建版本。
  - **指定版本**：将线上站点锁定到某个特定的已保存版本，使您可以继续私下开发而不影响公开站点。
- **徽章移除**：**Pro** 和 **Max** 订阅用户可以关闭已发布应用上的 "Built with Atoms" 徽章。

---

## 发布到 GitHub 或 GitLab

您还可以使用以下任一方法，将您的 Atoms 项目代码直接发布并同步到外部 GitHub 或 GitLab 仓库：

### 选项 1：手动上传（推荐）

1. 从 Atoms 编辑器下载您的项目源代码文件。
2. 将这些文件手动上传到您的 GitHub 或 GitLab 仓库中。

### 选项 2：通过 AI 智能体自动推送

1. 向 AI 智能体提供您的目标仓库 URL 地址。
2. 向智能体提供您的个人访问 Token / Access Key。
3. 智能体会自动提交、创建分支，并将项目代码直接推送到您的仓库。

*注意：对于 GitLab 集成，您的仓库必须托管在可公开访问的域名上。*
