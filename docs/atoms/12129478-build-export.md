# 构建与导出

> 来源：https://help.atoms.dev/zh/articles/12129478-build-export
> 更新时间：2026年7月29日

## Atoms 可以直接将应用导出为 .apk 文件吗？

Atoms 不支持直接生成 .apk 文件。目前它适用于 Web 应用。


## Atoms 支持构建和部署 Next.js 项目吗？

Atoms 支持生成和编辑完整的 Next.js 项目代码，包括页面、组件和 API。你还可以下载生成的文件，用于本地开发或手动部署。不过，Atoms 目前 **不支持直接在平台上部署 Next.js 应用**。

要发布你的 Next.js 项目，你可以从 Atoms 下载该项目并手动部署。
