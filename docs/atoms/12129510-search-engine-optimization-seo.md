# 搜索引擎优化（SEO）

> 来源：https://help.atoms.dev/zh/articles/12129510-search-engine-optimization-seo
> 更新时间：2026年7月29日

搜索引擎优化（SEO）是一个改进你的网站的过程，使 Google 和 Bing 等搜索引擎能够理解、索引并在搜索结果中显示你的页面。优化你的内容可以在无需支付广告费用的情况下，提高自然且高质量的流量。

## 认识 Atoms 的 SEO 专家 Sarah

Sarah 是你专注于 SEO 优化的 AI 队友。她会帮助你生成结构化内容、优化 meta 标签、构建站点地图，并让你的网站为搜索引擎索引做好准备。

### Sarah 如何帮助你被索引

Google 会优先考虑清晰、相关且结构良好的内容。通过生成深入覆盖你的主题的详细文章，Sarah 能显著提高搜索引擎发现并索引你网站的可能性。

### 激活 Sarah 的 2 种方式

你可以在聊天或提示词中通过以下任一方法直接触发 Sarah：

1. **直接标签（@Sarah）**：在你的提示词或请求中添加 `@Sarah`。  
   *示例*：`@Sarah, please analyze my landing page and optimize all meta tags and SEO descriptions.`
2. **关键词方法（SEO）**：在你的提示词中明确提及 `SEO`（搜索引擎优化）。Sarah 会识别这个关键词，并在构建完成后自动将一次 SEO 扫描加入队列。

*注意：Sarah 仅在 **团队模式** 中可用。请务必在项目设置期间打开团队模式，或在请求 Sarah 之前先在聊天框中切换到团队模式。*

## 提升你的 SEO 并提交到 Google

项目发布并且完全正常运行后，请按照以下步骤提升你的 SEO，并确保你的网站能被 Google 快速索引。

### 第 1 步：告诉你的智能体你的域名和站点地图需求

使用你已发布的 URL 向你的 AI 智能体团队发送提示词：
- *"Here is my domain: [Your Published URL]. Help me boost my SEO and generate a sitemap.xml so my website can be indexed by Google."*

你的智能体会自动生成所需的 meta 标签、规范 URL 以及 `sitemap.xml` 文件。

### 第 2 步：在 Google Search Console 中验证网站所有权

为了加快索引速度，请在 Google Search Console 中注册你的网站：

1. **添加资源**：在右侧选择 **URL prefix**，然后粘贴你的域名 URL。
2. **选择验证方法**：选择 **HTML Tag** 验证方法。
3. **通过智能体添加 HTML 标签**：复制 Search Console 提供的 `<meta>` 标签，并向你的智能体发送提示词：  
   - *"Help me add this HTML meta tag into the `<head>` section of my homepage: [Paste HTML Tag Code]"*
4. **验证**：在智能体部署该标签后等待 5–10 分钟，然后返回 Google Search Console 并点击 **Verify**。

### 第 3 步：提交你的 Sitemap.xml

1. 从 Atoms 下载已生成的 `sitemap.xml` 文件，或获取它的 URL 路径。
2. 前往 Google Search Console 中的 **Sitemaps**。
3. 在 **Add a new sitemap** 下输入 `sitemap.xml`，然后点击 **Submit**。

## 用于立即索引的手动 URL 检查

虽然 Google 会随着时间自动发现页面，但你可以使用 **URL Inspection Tool** 来加快新文章的索引速度：

1. 打开 **Google Search Console**。
2. 将你的新页面的准确 URL 粘贴到顶部的搜索栏中，然后按 **Enter**。
3. 如果 Google 显示 *"URL is not on Google"*，请点击 **Request Indexing**。
