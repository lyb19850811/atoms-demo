# 问题报告

> 来源：https://help.atoms.dev/zh/articles/12129264-issue-report
> 更新时间：2026年7月27日

## 什么是问题报告？

当 AI 智能体在构建过程中遇到问题时，左下角会出现问题报告通知。你可以点击“Resolve”立即修复，或展开报告，在右侧面板查看错误日志和详细信息。

不要慌。提前知道该怎么做，可以帮你节省时间和积分。

## 开始前你需要了解的内容

发生错误时，Atoms 会在屏幕左下角显示问题报告通知。

**通知会显示：**

* 错误的简要描述
* 一个“Resolve”按钮，用于自动修复所有问题
* 一个可展开报告以查看详细错误日志的选项

右侧面板会显示 Bug Report，其中包含详细的错误日志、堆栈跟踪和系统信息，帮助你了解哪里出了问题。

**你可以选择：**

* 点击“Resolve”，让 AI 自动修复所有问题
* 或展开报告，在决定前先查看技术细节

## 如何报告问题

### 场景 1：页面卡住且没有出现“Resolve”按钮

如果你的页面卡死或无响应，并且你没有看到问题报告通知：

* 打开与 AI 智能体的聊天。
* 点击其最新消息旁边的“...” （更多选项）。
* 选择“Feedback”，并附上你的 Chat Link 和截图来描述问题。

这会将报告直接发送给我们的支持团队。我们会联系你并提供帮助。

### 场景 2：你看到了“Resolve”按钮

请按照以下步骤解决问题。

**Step 1: Click "Resolve"**

只需点击“Resolve”按钮。AI 智能体会自动分析并解决所有已识别的 bug。

通常需要 1 到 3 分钟。

重要提示：请等待每次尝试完成后再再次点击。多次点击会创建重复任务并浪费时间。

**Step 2: Check the result**

AI 完成后，你的预览会刷新。如果没有更新，请先尝试刷新你的浏览器。有时这只是缓存问题。

**Step 3: If the issue persists**

如果点击“Resolve”后错误仍然出现，你可以在右侧面板中手动查看错误日志以获取更多详细信息。如果你不确定如何修复，请直接联系支持团队。

* 打开与 AI 智能体的聊天。
* 点击其最新消息旁边的“...” （更多选项）。
* 选择“Feedback”并提供：
  * 你的 Chat Link
  * 错误或问题的截图
* 我们的支持团队会进行调查并直接为你提供帮助。
