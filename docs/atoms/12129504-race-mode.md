# 赛马模式

> 来源：https://help.atoms.dev/zh/articles/12129504-race-mode
> 更新时间：2026年7月29日

## 什么是赛马模式

不同的 LLM 在知识、推理和风格方面各有独特优势。 **赛马模式** 允许你同时在多个模型上运行相同的提示词并比较它们的输出。它通过并行生成答案来提高成功率。你可以快速比较不同 LLM 的输出，找到最佳结果。

## 如何使用

**步骤 1：** 在首页聊天框底部选择 **赛马模式** 。

**步骤 2：** 在开始聊天前，你可以尝试设置其他用于构建的 LLM。默认模式为 Auto。你可以点击 Auto 来自定义 LLM。

**步骤 3：** 点击齿轮图标。齿轮图标会打开 AI Model Selector 的弹窗。

**步骤 4：** 等待流程完成（5-10 分钟），然后选择最佳输出：

**步骤 5：** 在你选择最佳选项后，其他选项将被丢弃以节省存储空间。

### **替代步骤**

如需停止赛马模式，点击界面顶部的 **"停止"** 。

停止后，你可以：

- 选择你偏好的结果，或
- 让智能体为你选择一个。

**提示：**

1. 请注意：如果你的项目已启用 **Supabase** 或 **Stripe** 集成，则无法使用赛马模式功能。
2. 赛马模式比标准运行消耗更多积分。请提前检查你的积分余额，以防任务被中断。

## 赛马模式的优势

在复杂项目中，赛马模式可以帮助你：

- **更快工作** ：同时运行多个 LLM，快速测试想法。
- **获得更好的结果** ：并行尝试不同方法，提高找到正确输出的概率。
- **选择最佳方案** ：比较不同模型的优势，选择你最喜欢的结果。

## 何时使用赛马模式

赛马模式在以下阶段尤其有效：

1. **探索可能性**

   赛马模式通过在多个 LLM 上生成更多想法来加速头脑风暴。
2. **迭代原型**

   你可以借助多个 LLM 快速修复错误，从而迅速迭代原型。
3. **测试阶段**

   你可以测试哪种提示词、文案或 UI 设计更好。然后生成多个输出并选择最佳方案。
4. **评估 LLM**

   并行运行主流 LLM，看看哪一个最适合你的使用场景。这有助于你为项目选择合适的模型。
5. **减少幻觉**

   赛马模式通过使用多个 LLM 交叉验证结果来降低幻觉风险。

## 常见问题

<AccordionGroup>
<Accordion title="我应该使用赛马模式吗？">
你可以通过两种方式使用赛马模式：

1. 相同的 LLM，多个版本

并行运行相同的 LLM，为创意想法、代码编辑或逻辑测试等任务生成多个结果。这会为你提供更多样化的输出，并帮助你更快找到最佳结果。

2. 多个 LLM 同时运行

对于复杂任务，你可以同时运行不同的 LLM，以覆盖更多方面和关注点。赛马模式让你能够利用每个模型的优势。
</Accordion>
<Accordion title="我是初学者。赛马模式适合我吗？">
这取决于你的项目复杂度和目标，而不是你的经验水平。

- 对于简单项目，常规模式已经足够。
- 如果你需要更高的准确性、稳定性，或希望快速比较不同 LLM，赛马模式会更有效。

不用担心——我们已准备了一份简短的新手指南，你可以在这里查看：

[Quick Start](https://help.atoms.dev/en/articles/12128979-quick-start)
</Accordion>
<Accordion title="选择赛马模式后，我还能像平常一样使用 Atoms 吗？">
可以。只需选择最佳结果，然后像平常一样使用 Atoms 即可。

⚠️ 注意：如果你的项目已集成 Supabase 或 Stripe，则不支持赛马模式。
</Accordion>
<Accordion title="我没有 Max 套餐。还能体验赛马模式吗？">
抱歉，赛马模式仅对 Max 套餐用户开放，因为同时运行多个 LLM 成本较高。
</Accordion>
<Accordion title="赛马模式还有其他限制吗，比如项目类型或文件大小？">
没有。赛马模式适用于所有项目类型和大小。

但它会消耗更多积分，因此请检查你的余额——如果积分用完，你的项目生成可能会失败。
</Accordion>
<Accordion title="赛马模式真的比常规模式好很多吗？">
- 对于 **开放式任务** （没有唯一正确答案），例如文案撰写、创意工作或推理，由于多个 LLM 会提供多样化输出，因此你可能获得更好的结果。
- 对于 **封闭式任务** （如事实核查或数据检索）这类需要单一正确答案的任务，不同 LLM 往往会产生相同结果，因此收益较小。
</Accordion>
