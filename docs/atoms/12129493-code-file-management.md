# 代码与文件管理

> 来源：https://help.atoms.dev/zh/articles/12129493-code-file-management
> 更新时间：2026年7月29日

排查 Atoms 中的超长代码文件、系统缓存故障以及磁盘存储损坏错误。

## 管理超长代码文件

处理大型代码库时，请提示 Atoms 将单体文件拆分为更小的模块化组件和工具模块，以避免单个文件变得过大或难以维护。

---

## 修复磁盘存储和缓存问题（“系统文件已损坏”）

如果你看到此错误：*“当前项目系统文件已损坏。你可以克隆之前的正确版本或联系支持团队。”*，请按顺序尝试以下修复方法：

### 修复方法 1：刷新并检查连接
1. 刷新你的浏览器页面。
2. 检查你的网络连接。

### 修复方法 2：清除浏览器缓存
过期的缓存文件通常会触发错误的存储报错：
- **Chrome**: `⋮` → **设置** → **隐私和安全** → **清除浏览数据** → 选择 *“缓存的图片和文件”* → **清除数据**。
- **Safari**: **偏好设置** → **高级** → 勾选 *“显示‘开发’菜单”* → **开发** → **清空缓存**。
- **Firefox**: `☰` → **设置** → **隐私和安全** → **Cookie 和网站数据** → **清除数据**。

### 修复方法 3：释放磁盘存储空间
1. 前往 **设置** → **通用** → **磁盘空间** → **管理** 以检查你的使用情况。
2. 从你的 Projects 页面删除未使用的聊天，并确保勾选 **“删除磁盘空间”**。

### 修复方法 4：克隆或联系支持
如果在清除缓存并释放磁盘空间后错误仍然存在，请将你的项目克隆到之前可正常工作的版本，或通过聊天联系支持团队。
