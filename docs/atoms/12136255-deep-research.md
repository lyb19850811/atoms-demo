# 深度研究

> 来源：https://help.atoms.dev/zh/articles/12136255-deep-research
> 更新时间：2026年7月29日

## 什么是深度研究（DR）

深度研究（DR）是一项用于生成专业报告的功能，包括学术论文、商业分析、市场报告等。Atom 的深度研究员 Iris 会接管你的复杂任务，通过搜索信息、筛选可靠来源，并生成一份供你审阅的报告。

Iris 生成的报告结构清晰、可靠且可追溯。每一条观点都有可信来源支持，以避免 AI 生成的幻觉。你只需一键即可将报告转换为网站、PPT、PDF 或 Docs。

它不是普通的搜索引擎，而是一位专业的研究员和精准的写作者。

当你需要可靠的信息和可交付的输出时，就是 @Iris 并使用 DR 的最佳时机。

## 如何使用

**步骤 1：** 点击聊天框底部的按钮。

**步骤 2：** 与 Iris 对话，并向她提供有关你项目的基础信息。随后，Iris 将开展研究。稍等片刻后，你可以将报告下载为 .pdf 或 .md 文件。

**另一种方式：** 你只需点击页面上的参考编号，即可追溯任意来源。

## 使用 DR 的最佳时机

1. **用于高准确性场景：** 学术研究、商业分析、市场研究，或任何专业报告。
2. **用于可交付输出，** 例如文档、PowerPoint 演示文稿或网站。
3. **用于团队协作：** DR 默认只能在团队模式中启用。
4. **用于复杂策略，** DR 提供比标准聊天更结构化、更可靠的综合研究框架。

**注意：**

1. DR **仅在团队模式中**可用。
2. DR 会在每条消息或每次克隆后**自动关闭**，必须手动重新启用。
3. DR 比标准搜索消耗**更多积分**。如果积分耗尽，生成将失败，因此请**提前规划你的使用**。
4. 只有在**关闭 DR 后**，才可以使用其他模型。
5. DR 与**赛马模式**不兼容。
