# 快速开始

> 来源：https://help.atoms.dev/zh/articles/12128979-quick-start
> 更新时间：2026年7月29日

欢迎使用 Atoms！本指南将带你了解核心概念、团队结构以及分步工作流程，帮助你将提示词转化为已发布的 Web 应用。

## Atoms 是什么？

Atoms 提供了一个由专业 AI 智能体组成的协作团队，帮助任何人使用自然语言构建网站、Web 应用和数据项目。你的 AI 团队成员会在标准化协议下协同工作，对你的项目进行规划、构建和优化。

### 认识你的 AI 团队成员

- **Mike (Team Leader)**：协调任务分配和整体项目执行。
- **Emma (Product Manager)**：分析需求并开展市场调研。
- **Bob (Architect)**：设计系统架构和技术规范。
- **Alex (Engineer)**：编写代码、构建组件并部署应用。
- **David (Data Analyst)**：处理数据集并创建可视化图表。
- **Iris (Deep Researcher)**：收集网络信息并整理分析报告。
- **Sarah (SEO Specialist)**：生成多语言 SEO 优化内容，以提升搜索可见性。

## 工作流程与模式

有时你需要整个团队来完成复杂任务，有时你只需要一位专业人士。你还可以 [在不同模式之间进行选择](https://support.mgx.dev/en/articles/12129385-mode-switching-guide)，包括团队模式、工程师模式、赛马模式和深度研究模式。

### 3 种开始方式

1. **原始提示词**：从你的原始提示词开始，或者先对其进行润色以节省积分。
2. **克隆现有项目**：先从我们 App 世界中的一个现有项目[克隆](https://support.mgx.dev/en/articles/12129010-remix)开始。

## 编辑与优化

在一个地方完成预览、修复 Bug、编辑代码、修改视觉元素和添加参考资料：

- **预览**：在移动端和 PC 模式下[查看](https://support.mgx.dev/en/articles/12129698-app-viewer)你的作品。
- **更改视觉元素**：在 App 预览 页面编辑你的视觉元素，你可以手动调整，也可以与智能体讨论你的期望效果。
- **添加参考资料**：你是否已经有了灵感参考？只需将其[上传](https://support.mgx.dev/en/articles/12129040-upload-file-folder)给智能体作为参考即可。
- **修复 Bug**：当你点击[修复 Bug](https://support.mgx.dev/en/articles/12129264-bug-fix)时，智能体会帮你修复问题。

如需更详细的说明，请参阅 [App 预览](https://support.mgx.dev/en/articles/12129698-app-viewer)。

## 连接集成

当 Atoms 准备好你的前端页面后，你可以使用 Atoms 云，或与 Supabase 集成，以实现数据存储、密钥管理和更多后端能力（例如向用户发送欢迎邮件、调用 AI 服务以及处理在线支付）。

### 连接 Supabase 的基本步骤

1. **第 1 步**：前往 **Settings**，打开 **Connectors**，找到 **Supabase**，然后点击 **Connect** 开始授权。
2. **第 2 步**：通过弹窗登录你的 Supabase 账户（如果你还没有账户，也可以注册一个）。
3. **第 3 步**：点击 **Authorize Atoms**。
4. **第 4 步**：选择一个现有的 Supabase 项目，或点击 **Add New One** 立即创建一个新的组织。

如需完整的集成说明，请参阅 [Supabase 集成](https://support.mgx.dev/en/articles/12129788-supabase-connect)。

## 发布与分享

- **发布**：点击右上角的 **Publish** 按钮来[发布](https://support.mgx.dev/en/articles/12129354-publish)你的项目。
- **分享**：点击右上角的 [Share](https://support.mgx.dev/en/articles/12129279-share) 按钮，在我们的 **App 世界** 或社交媒体上分享你如何与 Atoms Agents 一起构建项目。
