# 部署选项

> 来源：https://help.atoms.dev/zh/articles/12129483-deployment-options
> 更新时间：2026年7月29日

了解 Atoms 为您的项目提供的不同部署和预览选项，包括本地部署方式和 HTML 预览。

## 本地项目部署

**可以。** 您可以使用以下任一方法，在您自己的机器或私有基础设施上本地部署您的 Atoms 项目：

1. **直接下载代码**：直接从 Editor 面板将您的项目源代码下载为 `.zip` 压缩包，并在您的本地开发环境中运行。
2. **GitHub / GitLab 集成**：向您的 AI 智能体团队提供仓库地址和 Personal Access Token，以便自动将代码库提交并推送到您的 GitHub 或 GitLab 仓库，用于本地配置和 CI/CD 部署。

---

## HTML 文件部署与预览

目前暂不支持将静态独立 HTML 部署作为一键托管选项。

### 如何在 Atoms 中预览 HTML 文件

要在 Atoms 界面内预览 HTML 文件：

1. 打开工作区右侧的 **Editor** 面板。
2. 在代码查看器中选择并打开您的 `index.html` 文件。
3. 点击编辑器左下角的 **Play / Preview** 图标，以启动交互式实时预览。
