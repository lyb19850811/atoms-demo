# 错误信息指南

> 来源：https://help.atoms.dev/zh/articles/12129490-error-message-guide
> 更新时间：2026年7月29日

在与你的 AI 智能体团队协作时，排查常见错误信息和构建失败问题。

## 在聊天中处理错误信息

当你在项目开发过程中遇到错误信息或构建失败时：

1. **分享完整错误日志**：将完整的错误日志、回溯信息或截图复制并粘贴到聊天输入框中。
2. **让智能体直接检查**：@ 你的工程师智能体（例如 `@Alex`），并请他们分析堆栈跟踪。
3. **自动修复**：智能体团队会检查失败日志，并自动应用有针对性的代码修复。

---

## 如果智能体持续遇到错误该怎么办

如果你的 AI 智能体反复遇到执行错误：

- **优化提示词清晰度**：明确你的提示词指令，并指定清晰的文件路径或要求。
- **拆分任务**：将大型或复杂的功能需求拆分为更小的模块化实现步骤。
- **检查缓存和存储**：确认你的浏览器缓存已清除，并且项目磁盘存储有足够的可用空间。
