# 模式概览

Atoms 提供专为你的工作流程打造的专业模式。无论你需要快速原型设计、复杂协作，还是深入研究，选择合适的模式都能在速度、成本和功能之间取得平衡。

## 工程师模式

通过这个快速高效的选项最大化利用你的资源，该选项仅启用 **@Alex** 工程师智能体。非常适合构建简单网站、生成快速原型和创建演示，此模式在降低积分消耗的同时，仍能根据你的提示词提供同样高质量的结果。

## 团队模式

对于复杂或通用需求，此模式会集合多个智能体组成团队协同工作。它可以处理更广泛的场景——例如市场研究或数据分析——为你提供更多样化的输出类型。虽然这种更丰富的功能确实会消耗更多积分，但它为更高要求的任务提供了所需的能力。

在这里了解更多有关智能体团队角色的信息：**[Your Agent Team](https://help.atoms.dev/en/articles/12129380-your-agents-team)**。

## 赛马模式

**赛马模式** 可让你同时在多个模型上运行相同的提示词。这种并行方式能提高你的成功率，并让你快速比较不同输出，因此你可以轻松选择最符合需求的最佳结果。

由于成本较高，赛马模式目前仅对 Max 用户开放。

## 深度研究模式

**深度研究 (DR)** 由 **@Iris** 驱动，这是一款 AI 智能体，专为拆解复杂任务并为商业、学术或市场分析创建专业报告而设计。与标准搜索引擎不同，Iris 更像是一位精准的研究员——收集信息并验证来源，以确保每个细节都可靠且可追溯。

你可以一键将这些结构化报告即时转换为网站、演示文稿或文档。当你需要可信的信息和可直接使用的结果时，只需使用 **@Iris** 即可开始。

# 如何使用

1. 切换模式

   - 点击首页输入框左下角的模式切换按钮。
   - 在弹出菜单中选择工程师或团队。
   - 新对话会记住你的选择。
2. 随时切换

   - 无论是在项目开始前还是进行中，你都可以随时切换模式，以满足不断变化的需求。
3. 查看对话模式

   - 在 App 世界中，你可以在项目详情页的标签栏查看每个项目使用的模式（工程师或团队）。
