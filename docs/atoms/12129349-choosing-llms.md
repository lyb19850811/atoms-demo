# 选择 LLM

> 来源：https://help.atoms.dev/zh/articles/12129349-choosing-llms
> 更新时间：2026年7月29日

## 概览

简而言之，追求最高质量请选择 Claude，追求最低成本请选择 DeepSeek，需要经济实惠的编程支持请选择 Qwen，追求速度请选择 Gemini，而 GPT-5 则适合更均衡的选择。

| **Model**            | **Strengths**                                                         | **Weaknesses**                         | **Best For**                                                                    |
| -------------------------- | --------------------------------------------------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------- |
| **Claude Sonnet 4**  | 最稳定、最准确。擅长复杂推理和高质量输出。 | 成本最高。对于简单任务来说有些大材小用。     | 构建可用于生产环境的应用、精致的网站以及高要求的编程项目。   |
| **GPT-5**            | 在质量与推理能力之间取得了很好的平衡。能够很好地处理复杂文档。   | 响应速度最慢。                      | 技术文档、研究报告，以及对速度要求不高的编程任务。 |
| **Qwen3-Coder-Plus** | 比 GPT-5 更便宜、更快。适合编程和创意草稿。        | 对于关键任务项目来说可靠性较低。 | 预算有限的编程支持、头脑风暴和轻量级创意生成。            |
| **Gemini 2.5 Pro**   | 速度非常快。擅长总结和结构化报告。                  | 行文风格可能会显得重复。            | 快速原型设计、会议纪要、代码总结和快速报告草稿。            |
| **DeepSeek V3**      | 成本最低。能够较好地处理一般任务。                                | 输出可能缺乏深度和一致性。      | 快速实验、草稿撰写、低风险测试。                                  |

## 使用场景

1. **Claude Sonnet 4**

   Anna 是一名自由职业网页开发者，正在为客户构建一个电商网站。她需要像素级精确的代码和可靠的输出，因此她选择了 Claude，因为它稳定且准确。
2. **GPT 5**

   David 是一名研究人员，正在撰写一份 20 页的白皮书。比起速度，他更看重强大的推理能力和清晰的文档质量。他使用 GPT-5 来组织和润色报告。
3. **Qwen3-Coder-Plus**

   Lisa 是一名学生，周末在做一个个人项目。她希望在不过度花钱的情况下获得快速的编程帮助和创意点子，因此她选择了 Qwen，以获得经济实惠的支持。
