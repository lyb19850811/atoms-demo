# 团队工作区

> 来源：https://help.atoms.dev/zh/articles/12129353-team-workspace
> 更新时间：2026年7月29日

Atoms 让你能够与团队实时协作。升级到 Pro 或 Max 套餐后，你可以将设计师、开发者和产品经理汇集到一个统一空间中，更快地共同构建。

## 什么是工作区？

工作区是你团队的共享环境，用于在同一处组织项目并管理账单。每位用户注册后都会获得一个默认工作区。订阅 Pro 或 Max 套餐后，你可以邀请无限数量的团队成员进行协作。

你可以通过点击侧边栏左上角的工作区头像和名称，轻松切换不同工作区。

## 邀请队友

你可以在“成员”标签页中添加和管理协作者。只需前往“设置”>“成员”。

1. 前往“邀请工作区成员”部分。
2. 输入你希望邀请的队友邮箱地址（你可以一次粘贴多个邮箱）。
3. 点击“邀请”。

被邀请的成员将收到一封包含加入链接的电子邮件。在你的“成员”列表中，他们的状态会显示为“已发送邀请”，直到他们接受邀请，之后会更新为“活跃”。

**注意：** 工作区中的所有成员共享该工作区集中计费套餐中的积分。你可以在“成员”列表的“总用量”列下跟踪每位成员消耗了多少积分。

## 工作区角色与权限

目前，我们的工作区支持两种角色：Owner 和 Editor。

## 共同构建

我们的聊天界面支持同步的实时协作。工作区中的所有用户都可以同时进入同一个聊天页面并与智能体交互。

你将能够看到其他用户发送的所有历史消息，并通过他们的头像和名称加以区分。

## 常见问题

<AccordionGroup>
<Accordion title="积分如何计费？">
我们采用集中计费。所有被邀请加入你工作区的成员都会使用你的 Pro 或 Max 套餐的共享积分池。
</Accordion>
<Accordion title="一个工作区可以有多少成员？">
Pro 和 Max 套餐支持无限成员。免费套餐工作区仅限 Owner 使用（1 个席位）。
</Accordion>
<Accordion title="我可以属于多个工作区吗？">
可以。你可以加入任意数量已邀请你的工作区。可使用侧边栏在它们之间切换。
</Accordion>
<Accordion title="谁来为工作区付费？">
工作区 Owner 的套餐决定积分池。所有成员共享相同的积分。成员使用的是他们当前所在工作区的积分，而不是个人工作区的积分。
