## **2026-07**

### 2026-07-13

此次更新改进了 **项目搜索、长时间运行的 Chat 任务、已发布链接和分享奖励。** 你现在可以直接搜索项目内容和文件路径、查看单条 Chat 消息的积分使用情况，并查看更清晰的公开 Chat 访客数据。长任务、停止操作、已发布 URL 和奖励确认现在也应当更容易理解。

#### 新功能

* **项目搜索：** 你现在可以在项目内搜索文本内容、文件名和文件路径。对于包含大量文件的项目，这能让你无需逐层展开文件夹，就更轻松地找到正确的文件或代码片段。
* **公开 Chat 的独立访客统计：** 公开 Chat 现在除了浏览量外，还可显示独立访客数，帮助你更好地了解实际有多少人访问了分享内容。
* **积分使用详情：** 每条消息下方的“...”菜单现在可显示该 Chat 消息的积分使用情况，帮助你大致了解单个任务消耗了多少积分。
* **长 Chat 的连续性改进：** 在多轮对话或长时间运行的任务中，Atoms 现在会自动整理上下文，以减少因对话过长导致的信息遗漏、误解或任务中断。
* **本地图像生成支持：** 对于已配置兼容本地图像模型的用户，Atoms 现在支持通过本地服务进行文生图生成，包括批量生成。

#### 改进

* **更快的 Chat 发送反馈：** 发送消息后，Chat 会更快显示已接收状态，减少你对消息是否成功发送的不确定感。
* **更易判断的搜索结果：** 搜索现在会综合考虑文件内容、文件名和路径，并优先显示更相关或最近更新的结果。
* **更一致的已发布链接：** 发布后，项目 URL 将更好地匹配实际可打开的链接，减少已发布项目打开旧链接、错误链接或等待同步的情况。
* **更早的余额警告：** 当 Cloud & AI Balance 不足以支持部署时，Atoms 会在继续之前更早发出警告，而不是在发布流程后期才失败。
* **更清晰的分享奖励确认：** 在发放一次克隆分享奖励后，相关 Chat 现在可以显示奖励确认。单次奖励金额和每月奖励上限也会显示得更清楚，使奖励规则更容易理解。
* **带特殊字符的命令执行更可靠：** 在需要运行命令的场景中，包含引号、尖括号及其他特殊字符的内容将被更准确地保留，减少因命令被改动导致的失败。

#### Bug 修复

* **长时间运行的 Chat 任务与停止操作：** 修复了 Chat 在思考、停止或长时间运行时可能卡住的问题，包括状态显示不准确或停止后仍持续等待的情况。
* **模型选择与任务继续：** 修复了 Chat 中所选模型可能意外被重置，或在回答澄清问题后任务未继续的问题。
* **搜索、文件和 Preview：** 修复了搜索结果缺少路径、行号不准确、深层嵌套文件显示异常，或部分文件和 Preview 无法正常打开的问题。
* **发布与域名：** 修复了项目 URL 在发布后未同步、链接无法打开，或更改后旧域名和绑定仍然保留的问题。
* **分享奖励与公开访问：** 修复了分享奖励未正确到账、奖励记录显示不准确，或公开 Chat 访客统计重复或不准确的问题。
* **图像生成与页面验证：** 修复了图像生成失败、透明背景图像处理不正确，或页面验证评分不准确的问题。
* **复杂任务结果更清晰：** 修复了复杂任务产生重复回复、输出混杂，或误导用户执行不必要手动操作的说明问题。

## 2026-06

### 2026-06-15

此次更新让 **团队协作、连续 Chat 工作流、Overview 浏览和页面验证更加顺畅**。Pro / Max 工作区现在可邀请更多协作者，Prompt Queue 现在提供更灵活的发送选项，项目资源和公开文件也更易于查看、分享和管理。

#### 新功能

- **Pro / Max 工作区支持更多协作者：** Pro 和 Max 工作区现在支持无限协作者席位，让团队更容易共同构建、编辑和管理项目。免费工作区仍保持单成员限制。
- **Prompt Queue 中的立即发送：** 队列中的消息现在可以立即发送，无需等待其原始顺序。如果发送失败，消息会返回队列，以帮助防止内容丢失。
- **按项目控制 Atoms Badge：** 在支持的项目中，你可以选择是否显示 Atoms Badge。如未修改，则项目会遵循账户默认设置。
- **更丰富的 Overview 浏览：** 视频和海报示例现在可以显示当前语言的标题、描述和提示词。海报示例还包含封面图，使其更易于浏览和选择。
- **更便捷的公开文件分享：** 某些公开文件现在可以通过公开链接打开和下载，使其更容易从公开页面或外部场景中分享。
- **页面验证：** 在支持的场景中，Atoms 可以检查生成的页面是否按预期工作，并显示按钮、表单、导航和核心交互的验证进度、结果和评分。
- **集中式媒体资源管理：** 生成的图片、音频和视频现在会在项目资源文件夹中更清晰地组织，便于查找、复用和管理。

#### 改进

- **更清晰的工作区套餐指引：** 在降级套餐时，页面现在会更清楚地显示当前成员数量和目标套餐限制，便于了解需要先调整哪些成员。
- **新工作区更一致的协作权限：** 对符合条件的付费用户，新创建的工作区现在会更可靠地继承当前套餐中的成员席位和邀请权限。
- **用于发布的 Logo 和图片生成：** Logo 生成现在支持透明背景，并更贴近所请求的主题。在支持的场景中，图片生成也支持更多模型、格式和背景选项。
- **更真实的页面验证：** 验证现在能更恰当地处理登录、注册、支付和结账流程。对于游戏和高交互页面，它会更关注核心操作是否产生可见反馈。
- **更清晰的 Preview 反馈：** Preview 链接检测更准确，减少打开错误页面的情况。当截图耗时更长或页面加载超时时，反馈也更清晰。
- **简单任务启动更快：** 对于明确且范围较小的请求，Atoms 会减少不必要的规划确认步骤，以便更早开始生成和编辑。

#### Bug 修复

- **协作与套餐：** 修复了部分 Pro / Max 工作区无法正确邀请成员，或降级指引不清晰的问题。
- **克隆 Preview 体验：** 修复了某些克隆项目在 Preview 中打开错误页面的问题，并改进了克隆后项目资料未正确继承的情况。
- **连续 Chat 和队列状态：** 修复了 Prompt Queue 未按预期继续发送的问题，并减少状态变更后具有误导性的 Chat 状态提示。
- **Overview 资源显示：** 修复了已删除资源仍显示在 Overview 中、封面图无法打开，或资源标题和类型显示不准确的问题。
- **公开文件与 Atoms Badge：** 修复了某些公开文件无法打开或下载的问题，并提升了 Atoms Badge 在公开页和嵌入页上的显示一致性。
- **页面验证：** 修复了验证中的漏点点击、截图失败、页面重复打开、错误重定向、空白页、误填登录/注册表单，以及复杂页面评分不准确等问题。
- **生成与项目使用：** 修复了在服务繁忙时图片、音频或视频生成可能失败的问题，以及可能影响项目资源处理或中断后恢复的问题。

### 2026-06-08

此次更新带来了 **Chat 消息排队、多语言 Connector 描述，以及钱包相关页面中的奖励总额可见性**。同时还改进了 App Info 同步、部署域名显示、文件访问、媒体归档和构建恢复，并修复了消息排队、文件预览与下载、App 预览、多语言显示、版本处理和账户状态中的已知问题。

#### **新功能**

- **Chat 消息排队：** 在支持的场景中，当智能体仍在处理当前任务时，后续消息可加入队列，并在当前轮次结束后发送。该能力将在可用场景中逐步推出。
- **队列管理：** 队列中的消息现在可以暂停、恢复、重排、编辑、删除或清空，使连续追问对话更易于管理。
- **多语言 Connector 描述：** Connector 现在可根据当前语言显示描述。当本地化内容不可用时，会显示原始内容作为兜底，以避免信息空白或缺失。
- **奖励总额可见性：** Cloud & AI 支付相关页面现在会显示累计奖励积分信息，使奖励到账情况更易追踪。
- **构建任务恢复：** 中断的构建恢复任务现在可以从指定位置继续，减少重复处理。

#### **改进**

- **App Info 同步：** 改进了 App Info 保存后的同步机制，使 Overview 中的标题、图标及相关信息能更快生效。
- **部署域名显示与切换：** 改进了部署域名配置和显示切换，使 Publish、Preview 和线上站点信息更清晰。
- **Chat 连续对话体验：** 改进了队列时机和状态检查。智能体完成当前轮次后，下一条排队消息会更快进入发送流程，在恢复队列或积分不足时也会提供更清晰的状态反馈。
- **模型选择与 Settings 体验：** Settings > General 中的默认模型选择器以及首页的模型下拉菜单，现在会更清晰地展示常用和推荐模型，同时保留 Auto 等现有条目。Settings 中重复的 Language 和 Theme 条目也已整理。
- **文件访问与媒体归档：** 改进了对 Chat 根目录及相关文件夹中的文件路径识别。生成的图片、音频、视频和音乐文件现在采用更一致的命名和归档方式，并对重名文件自动编号以避免覆盖。
- **存储和图片结果显示：** 存储中的长项目名称现在会截断显示，并支持悬停查看，以保持表格可读性。图片结果文件名和累计图片数量的处理也更加一致。
- **构建恢复体验：** 改进了构建恢复任务的进度计算、状态反馈、积分处理和恢复逻辑，使长时间运行任务的恢复更顺畅。

#### **Bug 修复**

- **Chat 队列与消息状态：** 修复了队列消息可能无法自动发送、暂停或恢复不正确、在用户停止智能体后仍继续，或发送过早、重复发送的问题。
- **Chat 列表与输入状态：** 修复了发送新消息后 Chat 状态未正确恢复为进行中、实时消息更新未及时刷新列表，或对话结束后输入框未重新聚焦的问题。
- **文件预览、下载与存储访问：** 修复了分享场景和管理模式中的预览链接问题、从 Chat 根目录浏览文件时出现的错误存储路径问题，以及 Chat 删除后剩余文件无法下载的问题。
- **App 预览与生成流程：** 修复了 App 预览相关问题、纯视频生成后 Editor 面板无法正确打开的问题，以及 Popular Images 中的布局问题。
- **多语言与 Connectors 显示：** 修复了多语言描述、兜底显示和页面渲染不一致的问题，减少 Connector 信息缺失或不准确的情况。
- **版本、Publish 与域名：** 修复了部分版本列表卡片中版本号缺失、解绑域名时重复报错或状态不一致，以及不同会话中 Publish 加载状态混杂的问题。
- **Settings、登录与账户状态：** 修复了在需要填写密钥的任务中，当全部或部分密钥被跳过时的消息发送问题。同时修复了切换账户后 Web/App 模式状态残留、Settings 提示 lingering，以及退出登录后重复重定向的问题。
- **移动端与交互细节：** 修复了移动端首页输入框间距、按钮间距、边框颜色、人工任务组件样式，以及高级功能下缺失 Theme 条目的问题。
- **媒体生成与构建恢复：** 修复了音乐文件名未正确传递、图片列表范围和累计图片数量不准确，以及构建恢复任务中恢复点、跨阶段继续或积分状态反馈不准确的问题。

- 修复了点击一次 Generate 可能生成两张重复图片的问题，减少重复生成和资源浪费。

## 2026-05

### 2026-05-28

此次更新带来了 **Video Mode 入口和视频编辑改进、更沉浸式的 Project 工作区、Project 下拉菜单、Project 引用，以及更灵活的密钥填写流程。** 同时还改进了 **多媒体生成、消息排序和账户安全。**

#### 新功能

- Video Mode 入口和视频编辑：现在可以更容易地从首页和创建入口找到 Video Mode 和 Create Video 提示。符合条件的用户可进入视频生成、预览和编辑流程，并在编辑器中获得更顺畅的缩放、片段选择、分割和本地导出体验。
- Project 下拉菜单和沉浸式工作区：Project 页面现在包含一个 Project 下拉菜单，提供 Go to Dashboard、积分、Settings、Connectors、重命名项目和详情等选项。侧边栏现在会在 Project 内部折叠，以提供更专注的工作区体验，而在 Project 外部则保持展开，以便更容易导航。
- Project 引用：Chat 引用已扩展为支持在同一条消息中组合不同内容类型。每条消息最多可包含一个 Project 引用，让你在克隆、复制或引用现有项目时更方便地提供上下文。
- 更灵活的密钥填写流程：当任务需要 API Key 时，用户现在可以跳过部分密钥配置并继续任务，之后再通过“填写 API Key”提示返回补充。这减少了当前聊天流程中的中断。

#### 改进

- 改进多媒体生成：在 AI SaaS 和 POD 电商等场景中提升了生成质量。视频、音乐和图片能力也已优化，使生成结果、预览和后续编辑流程更具连贯性。
- 改进 Chat 引用体验：文件、Projects、AI能力 和密钥现在可以更自然地组合。文件引用名称和预览名称也已统一，使引用内容更容易识别。
- 改进 Video Mode 交互：优化了 Video Mode 的状态管理、入口、公告和页面布局，以减少与其他生成目标的冲突，并更清楚地表明当前任务处于视频生成上下文中。
