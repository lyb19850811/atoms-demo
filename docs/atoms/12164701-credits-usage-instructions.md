# 积分使用说明

> 来源：https://help.atoms.dev/zh/articles/12164701-credits-usage-instructions
> 更新时间：2026年7月12日

您可以通过三种方式获得积分：每日赠送、月度订阅和奖励积分。所有这些都可用于兑换 Atoms 服务。

每天会优先使用免费积分。每个套餐周期内您有 25 个免费积分，每日上限为 15 个积分。未使用的积分会结转到后续几天，直到 25 个积分全部用完。每日分配可能会根据之前的使用情况进行调整，但总量保持不变。

如果您的积分已用完，您可以随时通过以下页面升级到更高档位，额度将立即生效。

-   **设置 → 套餐与账单** 页面
    
-   **定价 → 支付** 页面
    

以下情况下，未使用的积分会自动结转到下一个计费周期 **_(结转仅限一个月，并非永久有效)_**：

-   升级后结转的未使用积分
    
-   系统在每日固定积分（15）之外额外发放的附加积分（特殊情况）
    
-   通过邀请新用户获得的积分
    
-   通过兑换码获得的积分
    

积分可根据套餐档位随时调整
