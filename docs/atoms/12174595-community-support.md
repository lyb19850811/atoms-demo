# 社区与支持

> 来源：https://help.atoms.dev/zh/articles/12174595-community-support
> 更新时间：2026年7月28日

## 加入社区

你可以在 Atoms 仪表盘中加入或关注 Atoms 社区和社交渠道。

在 Atoms 仪表盘首页中，点击左侧边栏中的 **加入我们的社区** 。弹窗会显示当前可用的社区任务和积分奖励。

当前的社区任务可能包括：

**Discord：**

Discord 是一个社区和支持渠道。加入 Atoms Discord 社区，与其他用户交流、提出问题、分享想法、报告问题，并实时讨论 Atoms。

**X (Twitter)：**

X 是一个社交动态渠道。在 X 上关注 Atoms，以获取产品公告、功能更新、发布新闻、技巧以及团队发布的简短动态。

**LinkedIn：**

LinkedIn 是一个社交和公司新闻渠道。在 LinkedIn 上关注 Atoms，以获取公司更新、产品新闻、行业洞察和专业公告。

**Reddit:**

Reddit 是一个社区讨论渠道。加入 Atoms Reddit 社区，分享项目、讨论使用场景、提出社区问题，并与其他用户交流技巧。

完成可用任务最多可获得 **25 积分** 。可用任务、奖励数量和支持的渠道可能会发生变化，因此产品内的 **加入我们的社区** 弹窗才是准确信息来源。

![](/api/public/assets?key=uploads%2Fhelpcenters%2Fb609caf5-d676-4b4e-8268-b8d59db1b941%2Fcontent%2Fintercom%2F12174595%2F32d8e3a88146f22a-image.png)

其他 Atoms 渠道还可能包括 **GitHub** 作为开发者社区渠道，用于探索 Atoms 代码仓库、示例以及开发者相关更新。这不同于“设置 > 连接器”中的 GitHub 连接器；后者用于将 GitHub 连接到 Atoms，且除非 GitHub 出现在产品内弹窗中，否则它不计入“加入我们的社区”的积分任务。

**注意：** 社区和社交渠道不同于 Atoms 连接器。只有在“设置 > 连接器”中显示的服务才能作为 Atoms 连接器进行连接。

## 通过 Atoms AI Bot 获取帮助

为了提升自助服务体验，Atoms 文档网站现已集成 **AI Bot Assistant** 。如果你在使用 Atoms 时遇到任何问题，可以通过 **[帮助中心](https://help.atoms.dev/en)** 快速搜索文档、浏览常见问题，或直接与 AI 智能体聊天以获得个性化支持。

### 如何使用：

- 点击页面底部的 AI Bot 聊天气泡以开始对话。
- 在输入框中键入你的问题。
- 按 Enter 或点击发送进行提交。
- AI 将在 1–2 秒内回复，有时还会附上有帮助的文档链接。
- 你可以继续追问后续问题——支持多轮对话。
