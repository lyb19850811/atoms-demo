# Adrian：广告智能体

> 来源：https://help.atoms.dev/zh/articles/14342754-adrian-ads-agent-for-automated-campaigns
> 更新时间：2026年7月28日

## 什么是 Ads Agent

**Adrian** 是 Atoms 推出的 AI 驱动广告智能体，可模拟专业营销经理的工作流程。它会自动提取产品和落地页信息，生成广告文案和广告活动计划，并在广告活动获批后实时监控表现。

简而言之，Adrian 可以帮助您：

-   自动化广告活动创建（广告文案、定向、出价）
    
-   通过智能工作流程减少手动工作量
    
-   通过持续优化提升表现结果
    

## 开始之前

在使用 Adrian 扩展您的业务之前，这里有两个需要牢记的关键概念：

-   **Google Ads：** 一个付费平台，用于在搜索结果、网站和应用中推广您的产品。Adrian 会自动撰写广告文案、规划广告活动，并确保当潜在客户搜索相关词条时，您的产品能够展示出来。
    
-   **广告活动：** 一个结构化的营销单元，具有明确的目标、目标受众、预算、出价策略和创意内容。Adrian 会端到端生成并管理所有组成部分。您可以查看广告活动、设置目标（例如获取新用户）、定义目标受众、设置每日预算，并在 Atoms 的仪表板上监控表现。

## 如何使用 Ads Agent

**步骤 1：发布您的产品**

请确保您的产品具有公开 URL。这将作为广告的落地页。

**注意：** Adrian 基于域名投放广告活动。每个自定义域名只能连接到一个聊天。如果您克隆了一个带有广告活动的项目，并希望将其应用到新的聊天中，您需要先将该域名从旧聊天中断开连接，再将其重新连接到新的聊天。

**步骤 2：了解成本影响**

通过 Google Ads 投放广告会产生真实的财务支出。在继续之前，请确保您已了解预算并满足合规要求。

![](/api/public/assets?key=uploads%2Fhelpcenters%2Fb609caf5-d676-4b4e-8268-b8d59db1b941%2Fcontent%2Fintercom%2F14342754%2F9e0b5cfd04e32a77-Screenshot-2026-03-26-at-16_25_48.png)

**步骤 3：连接您的广告账户**

如果您还没有 Google Ads 账户，请创建一个并将其连接到 Atoms。验证可能需要几分钟时间，但您可以继续设置其他步骤。

您可以在 Google Ads 引导流程中跳过创建广告活动这一步。

![](/api/public/assets?key=uploads%2Fhelpcenters%2Fb609caf5-d676-4b4e-8268-b8d59db1b941%2Fcontent%2Fintercom%2F14342754%2F29cd59593c903e23-img_v3_0210a_d08d747b-05a1-4e3f-bed9-d0b1cabda4cg.png)

**步骤 4：启用转化跟踪**

Adrian 会自动配置跟踪，以衡量：

-   转化
    
-   用户行为
    
-   广告活动效果
    

**步骤 5：启动并监控**

广告活动上线后：

-   启用数据仪表板
    
-   跟踪关键指标：
    
    -   点击率（CTR）
        
    -   花费
        
    -   转化
        
    -   受众人口统计信息（年龄、性别）
        

您稍后也可以启用监控。

## 何时使用 Ads Agent 及最佳实践

### 在以下情况下使用 Ads Agent

-   您需要初始流量和曝光
    
-   您正处于没有现有用户基础的冷启动阶段
    
-   您即将发布一款新产品
    
-   您想验证自己想法的 MVP
    

### 最佳实践

-   从可控预算开始，以验证表现
    
-   根据早期数据迭代优化信息传达
    
-   在扩大投放支出之前，优先关注转化跟踪的准确性
    
-   将 Ads Agent 用作测试引擎，而不仅仅是部署工具
    

## 关键指标

1.  **总转化价值** – 所有转化带来的总收入（购买、注册、下载）。示例：10 次购买 × $50 = $500。用于展示广告的实际业务影响。
    
2.  **ROAS（广告支出回报）** – 每花费一美元所产生的收入。示例：$500 收入 ÷ $100 花费 = 5。ROAS 越高，说明广告活动效率越高。
    
3.  **CPC（每次点击成本）** – 每次广告点击的成本。示例：$200 花费 ÷ 50 次点击 = $4。是控制预算和优化广告活动的关键指标。
    
4.  **CPA（每次行动成本）** – 每次目标用户行为的成本。示例：$500 花费 ÷ 25 次转化 = $20/次转化。用于衡量以转化为重点的广告活动效率。
