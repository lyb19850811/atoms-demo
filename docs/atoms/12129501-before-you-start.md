# 开始之前

> 来源：https://help.atoms.dev/zh/articles/12129501-before-you-start
> 更新时间：2026年7月29日

在你开启 Atoms 之旅之前，请先查看前置要求和相关提示，以确保你的开发过程更加顺畅。

## 编程知识要求

**无需任何编程或软件开发经验。**

只需在聊天提示词中使用自然语言描述你想要构建的内容。你的 AI 队友将自动处理需求分析、系统架构、前端开发、后端集成和部署。

### 获得更佳结果的提示

- **明确你的目标**：描述你想要的布局、关键功能和视觉风格。
- **提供参考资料**：上传图片、线框图或文档来指导智能体。
- **给出迭代反馈**：如果输出结果不太理想，与智能体聊天以逐步完善结果。
- **技术用户**：如果你具备技术经验，可以指定框架、库或 API 结构来指导实现。
