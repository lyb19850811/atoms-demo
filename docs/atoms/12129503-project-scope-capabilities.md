# 项目范围与功能

> 来源：https://help.atoms.dev/zh/articles/12129503-project-scope-capabilities
> 更新时间：2026年7月29日

了解你可以使用 Atoms 创建什么、它的功能以及项目边界，将帮助你最大化发挥你的 AI 智能体团队的价值。

## 你可以用 Atoms 构建什么

借助 Atoms，你可以构建各种各样的 Web 项目：

- **个人网站**：完整网站、落地页或作品集，并支持 AI 辅助设计、排版和布局。
- **Web 应用**：无需编写复杂代码即可创建交互式工具和小型应用，包括分析仪表盘、计算器和交互式小组件。
- **深度研究与报告**：借助我们的深度研究功能（Iris），在 Pro 套餐或 Max 套餐中生成高级研究报告、学术摘要和市场分析。

你还可以在 **App 世界** 中探索想法，并克隆其他创作者创建的项目。

## 复杂商业软件

Atoms 针对快速原型设计、数据可视化、Web 应用和定制小游戏进行了优化。我们正在持续增强我们的智能体架构，以便随着时间推移支持越来越复杂的软件系统。

## 移动端与 Web 应用能力

目前，Atoms 主要专注于 **Web 应用开发**。虽然原生 iOS/Android 二进制应用和桌面可执行文件目前无法直接生成，但你仍然可以通过以下方式提供类似 App 的移动体验：

1. **渐进式 Web 应用（PWA）**：可直接安装到移动设备主屏幕上的 Web 应用，提供离线支持、推送通知以及接近原生应用的移动体验。
2. **响应式 Web 应用**：使用 TypeScript、Tailwind CSS 和 Shadcn-ui 等现代技术栈构建，可在各种屏幕尺寸下实现流畅渲染。
