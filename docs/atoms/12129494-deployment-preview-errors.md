# 部署与预览错误

> 来源：https://help.atoms.dev/zh/articles/12129494-deployment-preview-errors
> 更新时间：2026年7月29日

在使用你的 AI 智能体团队构建 Web 应用时，排查常见的部署和预览问题。

## 为什么网站只显示 "Hello World"？

当你已部署的网站或预览面板仅显示通用的 "Hello World" 占位页面时，这意味着生成的代码文件未写入指定的工作区路径。

### 如何修复

1. 在提示词框中使用 **`#`** 来引用你的项目工作区目录。
2. 明确指示你的智能体将构建代码写入正确的工作区路径（例如 `workspace/project_name`）。
3. 让你的工程师智能体验证 `index.html` 和入口文件是否已在活动工作区的根目录中生成。
