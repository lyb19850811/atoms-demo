# 探索创意想法

> 来源：https://help.atoms.dev/zh/articles/12255829-how-to-explore-your-creative-ideas-on-atoms
> 更新时间：2026年7月29日

在我们的 **App 世界** 中，你可以探索更多关于他人的想法、开发策略和提示词技巧。如果你喜欢别人的项目，你可以尝试[克隆](https://help.atoms.dev/en/articles/12129010-remix)它，或查看它的开发历史。

**[Play HexGL](/api/public/assets?key=uploads%2Fhelpcenters%2Fb609caf5-d676-4b4e-8268-b8d59db1b941%2Fcontent%2Fintercom%2F12255829%2F7b70289ab34c680d-pkifw)**

一款非常令人印象深刻的太空飞船竞速游戏。你可以直接在 App 世界 中体验它。此外，如果你在 GitHub 上看到一个很棒的项目，你只需在 GitHub 上分享链接并发送给智能体即可。

你可以告诉智能体：“你能从（链接）下载代码并部署它吗？”

![](/api/public/assets?key=uploads%2Fhelpcenters%2Fb609caf5-d676-4b4e-8268-b8d59db1b941%2Fcontent%2Fintercom%2F12255829%2F2fa80ec7e20795ef-E6-88-AA-E5-B1-8F2026-01-04-21_19_50.png)

**[Tarot Pixel Site](/api/public/assets?key=uploads%2Fhelpcenters%2Fb609caf5-d676-4b4e-8268-b8d59db1b941%2Fcontent%2Fintercom%2F12255829%2F08c6b87cec535f75-5ccdvd)**

一个带有怀旧美学风格的塔罗网站。如果你偏好其他特殊美学风格，可以上传一张图片作为智能体的参考。它们会根据你的品味来构建网站。

![](/api/public/assets?key=uploads%2Fhelpcenters%2Fb609caf5-d676-4b4e-8268-b8d59db1b941%2Fcontent%2Fintercom%2F12255829%2F0e906e78f2dafa92-E6-88-AA-E5-B1-8F2026-01-04-21_20_49.png)

**[2D Cartoon Tower Defense Game](/api/public/assets?key=uploads%2Fhelpcenters%2Fb609caf5-d676-4b4e-8268-b8d59db1b941%2Fcontent%2Fintercom%2F12255829%2F02a519b554626d29-uimh0)**

还记得当年和同学一起玩塔防游戏的美好时光吗？这是其中一个简单演示。要做出像这样的优秀案例，你需要一些提示词技巧。

当你与智能体交互时，提示词对获得好的结果起决定性作用。你可以给智能体提供详细且结构清晰的提示词，包括技术栈、项目的关键功能以及理想的 UI 设计。

![](/api/public/assets?key=uploads%2Fhelpcenters%2Fb609caf5-d676-4b4e-8268-b8d59db1b941%2Fcontent%2Fintercom%2F12255829%2Fb3e5b518a85021ee-E6-88-AA-E5-B1-8F2026-01-04-21_23_48.png)

**[3D Urban City Scene Design](/api/public/assets?key=uploads%2Fhelpcenters%2Fb609caf5-d676-4b4e-8268-b8d59db1b941%2Fcontent%2Fintercom%2F12255829%2F92dc0daed661acc2-0mx17)**

你是否曾梦想过建造自己的城市并成为它的市长？探索一座雨中城市的景象，在这里你可以想象建筑物的建筑风格、充满氛围感的天气，以及整体城市风貌。

![](/api/public/assets?key=uploads%2Fhelpcenters%2Fb609caf5-d676-4b4e-8268-b8d59db1b941%2Fcontent%2Fintercom%2F12255829%2F983207679192a077-E6-88-AA-E5-B1-8F2026-01-04-21_46_56.png)

**[Bomberman Style Game Dev](/api/public/assets?key=uploads%2Fhelpcenters%2Fb609caf5-d676-4b4e-8268-b8d59db1b941%2Fcontent%2Fintercom%2F12255829%2F1c1d1d234121dbcc-53aypd)**

Bomberman 是一款深受喜爱的童年经典。以下是在 Atoms 上创建你自己的梦想游戏的方法：

-   在提示词中清晰地概述游戏逻辑。
    
-   为智能体提供参考图片以指导创作。
    
-   使用 **[选中以对话/Edit](https://help.atoms.dev/en/articles/12129698-app-viewer)** 来修改特定视觉元素。
