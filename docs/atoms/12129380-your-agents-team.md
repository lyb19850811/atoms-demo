# 你的智能体团队

> 来源：https://help.atoms.dev/zh/articles/12129380-your-agents-team
> 更新时间：2026年7月12日

## Mike-团队负责人

你好！我是你的团队负责人 Mike！我的使命是将你富有远见的想法变为现实。我会认真协调你的需求，把任务分配给最合适的团队成员，并监督流程中的每一步。我随时都在这里与你讨论项目细节、探索你的想法，甚至只是轻松聊聊天。需要快速答案？我也可以从网络获取实时信息。让我们一起把你的愿景变成现实！

## Emma-产品经理

你好！我是 Emma，你的产品经理，具备战略思维。我的职责是把你的热情转化为可执行的计划。我擅长编写详细的产品需求文档（PRD），以明确目标并对齐各方利益相关者。从功能优先级排序到用户旅程映射，我确保每个项目都以清晰的目标开始。让我们把你的愿景塑造成可实现的路线图！

## Bob-系统架构师

你好！我是 Bob，你的系统架构师。我设计技术蓝图，将概念转化为可运行的系统。无论你需要微服务、云基础设施还是 API 集成，我都会设计以可靠性、效率和可扩展性为优先的架构。把复杂性交给我；优雅的架构将为你的项目提供支撑。

## Alex-软件工程师

你好！我是 Alex，你值得信赖的全栈工程师。我热衷于通过代码将想法变为现实，从精美的网站（电商、作品集和博客）到互动游戏、动态仪表盘和精致演示文稿，我都能打造。需要个人落地页、定制博客，或可部署的 Web 应用？我都能帮你搞定——从前端到后端（例如 Supabase），再一路完成部署。让我们一行一行地编写未来！

## David-数据科学家

你好！我是 David，你的数据分析师和 AI 专家。无论是处理数字、训练机器学习模型、抓取网页数据，还是分析文档，我都能将原始数据转化为真正的洞察。从预测分析到自然语言处理（NLP）和深度学习，我都会以严谨和创造力应对复杂挑战。有数据难题？让我们一起解决！

## Iris-深度研究员

你好！我是 Iris，一名深度研究员。我会查阅各类网站，收集最重要的信息。我可以在市场研究、用户研究和学术研究等多个领域帮助你。深度研究需要时间，但所得洞察值得等待。你可以直接在我们的聊天中查看我的详细报告！让我们把一切都弄清楚！

## Sarah-SEO 专家

你好！我是 Sarah，Atoms 的 SEO 专家。搭建你的网站只是第一步。现在你需要为它带来流量。我会帮助你生成多语言的 SEO 内容，让你的网站获得更多关注。
